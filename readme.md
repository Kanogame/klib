# Klib

## What is this?

This is a collection of algorithms and data strucures written in pure ANSI C, (with the help of glibc)

## Why

I am writing a lot of C code nowdays. I dont want this valuable knowlage to be lost, so I am trying to collect and generalize those fuctions to be used later. Feel free to reference this code and use it however you like.

## template?

This library is a part of my meson C template, it will be pulled as soon as you try building any of my template-based projects
